# Delivero — Product Demo Video Prompt (OTP Login)

Create a **75–90 second** premium product demo video for **Delivero**, a Flutter-based mobile food delivery app. The video should feel like a modern startup launch trailer: clean UI, fast pacing, and high trust.

## Goal

Show the complete flow: **OTP sign-in → browse → search/filter → customize → secure checkout → live tracking → delivery/rating → reorder → CTA**.

## Target audience

- Busy professionals, students, families
- People who want fast, reliable food delivery with real-time tracking

## Tone + style

- **Tone**: premium, calm, trustworthy (not playful)
- **Primary format**: **9:16 vertical** (Reels/TikTok/Shorts)
- **Optional exports**: 1:1 + 16:9 (keep safe margins)
- **Motion**: smooth swipes, subtle zoom-ins, minimal motion graphics
- **Music**: upbeat modern (not aggressive)
- **SFX**: light tap/whoosh; **one** notification ping during tracking updates

## Brand colors (from the app)

- **Primary (brand)**: **#2563EB**
- **Accent**: **#F59E0B** (use sparingly for offers/alerts/badges)
- **Hero / end-card gradient**: **#2563EB → #1E3A8A**

## UI recording requirements (to look cinematic)

- Record at **1080×1920** and **60fps** if possible
- Use **demo profile data** (no personal phone/address)
- Do slow, deliberate gestures (editor can speed up)
- Keep scrolls short and intentional

## On-screen text rules

- Max **4–6 words** per caption
- Place captions mostly in the **lower third**
- One font family, 2 weights (Bold headline + Regular caption)
- Use **#2563EB** for key highlights; avoid over-coloring
